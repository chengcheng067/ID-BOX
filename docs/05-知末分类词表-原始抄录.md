## 4. 抄录时观察到的结构性事实（供设计参考，不是设计结论）

1. **「一级分类」与「风格」是两排平行的筛选器**，不是父子关系。知末自己也没有把风格当作分类的子级。
2. **「一级分类」内部不是单一维度**，混了至少三种切分方式：
   - **场景尺度**：家装、工装、景观、建筑、展厅/展台、舞台、家装户型
   - **物件类型**：家具、灯具、植物、硬装构件、厨卫五金、电器/器材、美陈装置、标识广告、人物/动物、交通工具
   - **材质/其他**：软装陈设、SU材质  
     → 所以它**不是一棵干净的树**，直接拿来做嵌套目录会有语义重叠（一个「家装」场景里的沙发，既属于家装也属于家具）。
3. **顶层的「贴图材质」「CAD图纸」「方案文本」等 Tab 是另一套独立的一级分类**，其下各自有自己的一套分类，与 SU 模型频道的 19 项**不通用**。
4. 截图未覆盖其他 Tab 下的分类列表 —— 如果 ModVault 要对贴图/材质预设也照抄知末分类，**需要补充截图**。

## 5. 【2026-10-13 补录】筛选区其实是**三排**，二级分类随一级分类级联

用户后续又发来 6 张截图（并给出站点 `https://su.znzmo.com/sumoxing.html`），更正了第 4 节的判断：  
**「一级分类 / 风格」之间还有一排「二级分类」，且二级分类的取值随当前选中的一级分类变化。**

**补录时观察到的两条事实**：

1. **家具的二级分类里混进了品牌名**（Minotti、Poliform）——品牌不是分类层级，与「沙发/茶几」不同维。
2. **筛选区三排 = 两个分类维度 + 一个风格维度**。用户此前举的例子 `模型\家具\沙发\<资产名>` 正好对应「一级分类 = 家具、二级分类 = 沙发」，说明他要的两级语义 = 这两级，**风格是第三排的独立维度**。
