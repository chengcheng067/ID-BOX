# 第 2 段 · 施工中新增裁定（2026-11-09 晚）

> 本段全部为**施工中由主理人代裁**并已告知用户的事项。用户若不认可，改回只需改对应一处。

## 10. 插件「纯读方」硬约束的松绑（一处，有限）

| 项 | 内容 |
|---|---|
| 松绑内容 | 允许插件**写** `%APPDATA%\idbox_export\` 下的导出产物（收件箱） |
| 仍然禁止 | 写素材库目录、写 `%APPDATA%\idbox\plugin\`（主程序单方写）、改动任何既有资产文件 |
| 理由 | 「导出至 IDBOX」的物理前提就是插件要产出一个 `.skp` + 一张截图；不允许写盘则该功能无法存在 |
| 边界实现 | `exporter.rb` 的三道写盘闸门：目标必须在 `export_root` 下 / 不得落在 `%APPDATA%\idbox` 下 / 不得落在库根下 |

## 11. 收件箱协议（插件 → 主程序唯一通道）

| 项 | 契约 |
|---|---|
| 根目录 | `%APPDATA%\idbox_export\`（与 `%APPDATA%\idbox` **同级**，不在其内） |
| 任务目录 | `incoming\<jobId>\`，`jobId` 必须匹配 `^\d{8}-\d{6}-[0-9a-z]{4}$` |
| 产物 | `<名>.skp`、`<名>.cover.png`（`.cover.` 中缀是导入器识别封面的唯一判据）、`manifest.json` |
| 写入顺序 | `manifest.json` **最后写**，且 `.tmp` → `rename`（主程序看到清单时其余文件必已齐全） |
| 归档 | 成功 → `done\`（30 天后清理）；失败 → `failed\` + `error.txt`（中文原因，**永久保留**供排查） |
| 更新 | **就地覆盖那一个 `.skp`**（`.tmp` → `rename`）+ `rescan`。⛔ 严禁走 `importPaths` 覆盖档（会把旧目录整个进回收站、丢渲染参数与自定义封面） |
| 派发 | at-least-once（3s 重发 / 上限 40 次），渲染层按 `jobId` **永久集合**去重 |

## 12. 用户可见文案的统一口径（本轮踩了四次才定下）

**四次泄漏**：① `manifest.json` 被拷进用户素材库；② 界面出现 `manifest.generatedAt`；③ 界面出现 `apiVersion`；④ 设置页出现「归一化后的 key」/ `[{key,name}] JSON`。

| 判据 | 内容 |
|---|---|
| 主程序界面 | **文件名与字段名一律不出现**（`manifest.json` / `index.json` / `manifest.` 全禁）；路径可在 `title` 里保留一份供复制 |
| 插件面板 | 允许出现**文件名**（排查场景需要，用户能在资源管理器对上），仍**禁止字段名** |
| 排障细节 | 一律进内存态（Ruby 控制台可读）或 `reportLog`，不新造写盘通道 |
| 错误原文 | `err.message` / `reason` 只进日志，进 toast 的必须是中文人话 |
| 守卫写法 | 先剥注释再数字面量；**必须带负对照**（注释里故意留一处，证明剥离生效、断言不是空转） |

## 13. 折叠与插件的两处代价（已知并接受，注释里标「不要优化回去」）

- `UI::HtmlDialog` 无 `set_min_size` ⇒ `:min_height` 必须降到折叠高度 60，代价是用户可把窗口拖到 60px 高（可拖回）。
- 无 `get_size` ⇒ 任何"记住用户尺寸"只能靠 `innerWidth/outerWidth` 回写，会**累积漂移**；宁可「折叠后回默认 960×680」。
