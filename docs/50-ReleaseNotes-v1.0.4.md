> 上一版发布是 **v0.9.2**。中间没有推送过的版本一律不单独占段，它们的功能全部并入本版 —— 这份说明覆盖的是「v0.9.2 → v1.0.4」之间你能摸到的全部变化。

## SketchUp 插件：从「装上但不好用」到真能用

- **工具栏按钮**真的出现了。装好后 SketchUp 顶部多一个 ID BOX 按钮，点一下开面板；面板被关掉再点还能开，不用去菜单里翻。
- **面板整体换了一身皮**：自绘顶栏、品牌标识、版本号与本体一致。右上角一个折叠按钮，点一下整个窗口收成一条窄栏，建模时不吃屏幕。
- **预览大小三档**（大 / 中 / 小 = 2 / 3 / 4 列），点一下就换，下次打开还记得你选的哪档。
- **面板只列出能用的东西**：只显示 SketchUp 模型和材质。HDR、CAD 不出现；3ds Max 的 `.max` 和 `.skp` 在库里同属「模型」，以前会被一起列出来、点了也插不进去，现在按文件类型挡掉了。
- **单击模型卡** → 在视口里点一下落位，就是 SketchUp 自己的放置方式，随时 `Ctrl+Z` 撤销。插入成功后短暂显示「撤销 Ctrl+Z」，5 秒自动收起，状态栏平时是干净的。
- **材质双击即用**：双击贴图 / 材质卡，直接建好材质并设为当前材质，同时自动切到油漆桶工具 —— 想贴哪面贴哪面，我们不替你贴面。
- **右键「导出至 IDBOX」**：在视口里选中模型 → 右键 → 导出，先让你给个名字，再拿**当前视口画面**当封面，自动入库。所见即所得，不用另外截图。
- **右键「更新 ID BOX 中的这个模型」**：减完面、删完场景后原样回写，**覆盖同名模型本体，分类、渲染参数、自定义封面都不动**。这条不再要求你先选中，右键就能用；库里匹配到多个同名资产时给你一个子菜单自己选。
- **侧栏分类按大类算**：停在「全部」时不再把模型和材质的一级分类混成一张表；点进某个大类才展开，计数也只算这一类。

## 首页：新做的一整屏封面

- 侧栏第一项从「全部」变成 **「首页」**。点进去是一整屏封面页：粒子背景 + 数据卡片 + 变形搜索条 + 下方磨砂文件夹；左右两栏自动收起，点文件夹进分类时再滑回来。
- **粒子背景**：浅色 / 深色各一套配色，鼠标划过会被带动、点击会荡开一圈。跟随设置里的「动效性能」三档自动降级；系统开了「减少动态效果」就只画一帧静止画面，窗口切到后台也不耗电。
- **磨砂文件夹**：每个文件夹里探出该分类最近 3 个素材的缩略图。双击时**整个文件夹**飞到屏幕中央、再从中心消隐，然后才进分类 —— 这是重做过的过场，不再是缩略图乱飞或瞬间消失。
- **数据卡片**：一张正方形卡，三个数 —— 本月入库 / 库总量 / 待补分类。点「待补分类」直接跳到待补清单。不想要这张卡，设置里有开关可以关掉。
- **搜索框会变形**：首页中央靠下的搜索条，一打字同一个盒子连续长成结果面板（不是弹一个下拉），结果行带缩略图；空输入时显示最近搜索。输入第一个字就离开首页、直接进结果网格。库内顶栏的搜索是同一个东西，从左上往右下长。
- 首页只摆**有素材的**文件夹，空的分类不占位置。

## D5A：作为「模型的一种格式」收进来

- **`.d5a` 直接拖进 ID BOX 就能入库**，整包存档、不解包（包里是 D5 自己的私有格式，解出来既不能预览也插不进任何软件）。按名字能搜到、能管理。
- 没有封面时卡片是**紫色「D5A」品牌占位**（深浅两套配色）。想给它一张封面，用现有的截图粘贴就行。
- 入口统一成一条路：**「模型」→ 中栏头「格式」筛选 → D5A**。侧栏不单列大类，首页也不再单独给它一张文件夹卡 —— 之前「侧栏没有、格式里选不到、首页却单独一张卡」三处说法不一致，这次收回一处。
- 它**插不进 SketchUp**，这不是缺陷：D5 资产的宿主是 D5 Render。插件面板里干脆不显示它，避免点了没反应。

## 排序与「用了多少」

- **排序可以切换正序 / 倒序**了。每个排序键都能翻向；你没动过的时候保持原来的默认方向，所以升级后第一眼看到的顺序不会变。
- 新增两个排序键：**「最近使用」**（刚打开过的排前面，从来没打开过的排最后）和 **「最常使用」**（按次数加权，越久远的次数越不值钱 —— 14 天前的使用大约只算一半）。
- **什么算一次「使用」**：空格快览、双击看大图 / 进文件视图、双击预览 HDRI、把卡片拖到建模软件、在 SketchUp 插件里插入，各记一次。同一个资产 2 秒内重复打开只算一次，来回比图不会把计数刷爆。

## 侧栏与进出网格的动效

- **侧栏可以折成一条 48px 窄轨**：折起来只剩一列图标 —— 文字、计数、分组标题、底部的库路径与版本号一起收走，屏宽整个让给卡片。展开 / 收起是滑动过渡，不是瞬间跳；折过一次就记住，下次打开还是折着的。
- **侧栏的选中态换了一种语言**：一条竖直轨道贯穿导航，选中项在那里折出一段钩线接到文字上，标签滑进位置；悬停时补一段灰线接在它后面。颜色只用本项目自己的系统蓝，深浅主题各一套。
- **所有「进入卡片网格」的路径统一了入场**：从文件夹退回、切分类、搜索、跳转 —— 卡片一律从两侧边缘向内滑入并轻微错峰，不再有哪条路径是「啪一下出现」。
- **修掉「退回时像卡顿」那一下的根因**：以前进入网格会先按最终位置画一帧、再跳回起点，所以看着卡了一下。现在动画期间卡片照常能点、能双击 —— 动效不阻塞交互。

## 右键菜单：三种位置各管各的

- **卡片上右键**：进入文件夹 / 预览 HDR / 更换封面 / 自定义渲染 / 指派分类 / 复制资产名 / 复制文件夹路径 / 打开文件位置；在重复资产里还会多一条「保留这份，其余移入回收站」。
- **文件行上右键**：用默认程序打开 / 在资源管理器中显示 / 设为封面 / 复制文件名 / 复制完整路径。
- **网格空白处右键**：刷新 / 清除筛选。菜单只列当下真能用的项，不给你一堆点了没反应的入口。

## 更新说明直接弹给你看

- 启动时检查到新版本，不再只给一句「有新版本」—— 弹窗里直接显示这个版本**完整的更新内容**（就是这份说明）。
- 两个选择：**「稍后」** 本次启动不再打扰；**「跳过这个版本」** 这个版本以后都不再提示。
- 弹窗里的链接一律交给系统浏览器打开，不在软件内部跳转。

## 顺手修掉的几处

- **从 SketchUp 导出的模型不再夹带附属文件**：导出过程产生的中间文件不会跟着进你的素材库，也不会被算成资产的一部分。
- **「未分类」的四个说法合成一个**：侧栏数字、中栏提示、整理队列条数、设置页「重跑自动分类」的候选数，现在同一个判据；中栏那处文案改叫「待补」。
- **HDR 分类不再被文件名尾巴带偏**：知末的 HDR 文件名带一串标准包编号，以前会把词表命中咬掉，现在按显示名判定。
- **覆盖导入的旧版本有了交代**：旧版本能进回收站就进；被建模软件占用进不去时，就地改名成「原名.旧版本」留在同一个文件夹，并明确告诉你，确认没用了自己删。
- **插件索引写盘默认仍是关的**，但第一次进到那个开关时会有一段一次性说明讲清它写到哪、什么时候写，看完不再重复。
- **别名表可以带走换机器了**：设置里新增「导出别名表 / 导入别名表」两个按钮。导出的是一份能直接搬走的文件；在另一台机器导入是**合并**、不是覆盖，做完会告诉你有多少条写进去了、多少条因为格式不对被跳过 —— 一条都不合格式时，原来那些别名原封不动。

## 升级提示

**本体与插件必须同版本，插件要跟着重装一次** —— 否则面板会提示版本不匹配并禁用插入 / 建材质。

1. 先退出正在运行的 ID BOX，再运行 `IDBOX-Setup-1.0.4.exe` 覆盖安装。库与设置原地保留。
2. 打开 ID BOX → **设置 → 数据与备份** → 重新导出一次 SketchUp 插件包（`.rbz`）。
3. 在 SketchUp 里 **窗口 → Extension Manager → Install Extension**，选刚导出的包覆盖安装，重启 SketchUp。
4. 从 **扩展程序 → ID BOX** 打开面板。工具栏按钮没出现就再检查一次是否装到了 SketchUp 2021 及以上。

## 已知限制

- 主程序仅支持 Windows；SketchUp 插件要求 SketchUp 2021 及以上。
- 首页不再有「一屏看全库」的资产网格 —— 这是封面页形态的代价，看全库请用搜索或分类进入。
- `.d5a` 只能入库管理，不能插入 SketchUp，也不做自动封面（包内的贴图不是资产主图，我们不猜）。
- SketchUp 插件只显示 SketchUp 模型与材质，HDR / CAD / D5A 不在面板内。
- 插件侧栏的分类树只做到**一级**（点进某个大类才展开），二级留给后面的版本；这是刻意取舍，不是漏做。
- 首页背景目前只提供**粒子**一种；数据卡片可以在设置里单独关掉。换纯色底 / 换自己的图这两个入口这次没上。
