## 0. 最重要的结论（先看这一条）

**材质频道确实有「二级分类」排。** 本次实测 21 个一级中有 **20 个**在进入一级页后出现独立的「二级分类」筛选排，只有 **「其他」**没有二级排。

> 这条**推翻了** `docs/07` §5.11 的旧记录（原文：「材质…无二级分类排、无风格排」）。旧记录是在频道首页（`caizhi.html` = 全部）观察得出的——**频道首页本身不显示二级排**，必须先点进任一一级分类才会出现。与贴图频道行为一致（贴图频道首页也无二级排）。

因此：我方的「材质只有 21 个一级、没有二级」不是站方事实，而是**采集深度不够**。`材质/木纹/未分类` 里的 `未分类` 应改为真实的二级。

## 1. 判据说明（重要）

1. **以分类筛选树 / 分类节点页为准，不以商品详情页为准。** 知末素材详情页没有「所属分类」字段（`docs/17` 已记录同一事实），商品卡片上也不显示分类。唯一权威来源是分类筛选排与 `/caizhi/<slug>.html` 节点页。
2. **二级也有独立 URL**，形如 `https://tietu.znzmo.com/caizhi/<slug>.html`，与一级同目录。抽查：「哑光木纹」= `https://tietu.znzmo.com/caizhi/ygmw.html`，`<title>` = 「哑光木纹贴图材质免费下载_知末网」（已实测核对）。

## 6. 采集限制与不确定项（如实写）

1. **106 条二级的 URL 未逐条抄录**（只抄了名称）。已确认二级有独立 URL、格式为 `/caizhi/<slug>.html`，样例 `ygmw.html`（哑光木纹）已用 `<title>` 验证。若后续需要二级 URL 全集，需再逐个点击 106 次。
2. **「属 性」第四排只在外景、纸制品两页确认存在**，其余 19 个一级未逐页确认，不能断定有或没有。
3. **「风格」排：本次在材质频道 21 个一级页中均未观察到**（对比贴图频道每页都有风格排）。此为观察结论，未做穷尽验证。
4. **「材质类型」是独立于分类树的另一维度**：3D / SU / PBR材质 / C4D / Maya / Rhino / VRSCANS / 免费渲染器。其中「SU」「PBR材质」实测点击后跳转到**另一个独立页面** `https://tietu.znzmo.com/pbrcaizhi.html`，该页的「一级分类」是**完全不同的一套 14 项**：
   > 全部 / 木材 / 布料 / 石材 / 地毯 / 金属 / 皮革 / 塑料 / 植物 / 涂料 / 食物 / 人造的 / 自然 / 其他
   注意其中出现「**人造的**」「**自然**」这两个非材质名词的一级，且**没有**木地板、陶瓷、墙面、地面、外景、皮肤器官、液体、纸制品、半透明体。
   **该 PBR 页面的二级本次未抄录**（确认它是一套独立结构，需要单独一轮采集）。
5. **点击坐标存在系统性偏移**（截图与实际 CSS 视口横向约 0.856 缩放），早期若干次点击落到了相邻的一级上。本文所有条目均以**最终 URL + `<title>` 核对**为准，未采用「点击位置推断」；凡是 URL 未核对成功的条目一律未写入。
6. 站点未出现验证码/限流；未下载任何素材、未收藏、未点购买/充值、未提交表单。
7. 材质频道首页（`caizhi.html`）与一级页的**商品卡片不显示所属分类**，本文的分类归属**全部来自筛选排与节点页**，不来自商品页。

## 7. 给分类体系设计的提示（不是设计结论，仅供参考）

1. 我方要补的不是「一个材质二级」，而是 **21 个一级各自的一套二级**，共 106 项；且其中 20 个一级是「同构的三层结构」。
2. 材质频道的二级命名**全部采用「其他 ××」兜底项**：20 个有二级的一级，**无一例外**都以一个「其他××」结尾（其他石材/其他木材/其他木地板/其他地毯/其他布料/其他金属/其他皮革/其他玻璃/其他塑料/其他陶瓷/其他涂料/其他墙面/其他地面/其他植物/其他外景/其他皮肤器官/其他液体/其他食物/其他纸制品/其他半透明体）。这对我们的「未分类」落位有直接参考价值——**站方的兜底项是分类树里的正式节点，不是一个全局的"未分类"**。
3. 材质频道存在 **「高光/哑光/粗糙」光泽度三分**（木材、塑料、陶瓷 三个一级都有），这是一个**跨一级复用的切分维度**，值得在设计里单独考虑是否抽成属性而非类目。
4. 「其他」一级本身**没有二级**，说明站方允许「一级即终点」，我方「未分类」在这种一级下是合理终点。
