## 1. 图标体系（新增，v0.2 未定义）

### 1.1 规格

| 项 | 值 |
| --- | --- |
| 网格 | 24×24 viewBox，图形实际占位 20×20（四周留 2） |
| 描边 | **基准 = 16px 渲染尺寸上的视觉 1.5**；path 坐标写 `strokeWidth=2.25`（2.25 × 16/24 = 1.5） |
| 端点 | round cap + round join |
| 颜色 | 继承 `currentColor`，**不自带彩色、不画底框** |
| 渲染尺寸 | 导航 / 按钮 16；空态 40 |

### 1.2 颜色档

| 态 | 浅色 | 深色 |
| --- | --- | --- |
| 默认 | `#6B7280`（text-tertiary） | `#98989E` |
| 选中 | 随文字 `#007AFF`（只靠 tint 底 `#E1EFFF`，不加彩色描边） | 随文字 `#6DB2FF` |
| 禁用 | `#636368` | `#636368` |

### 1.3 尺寸换算（等比缩放，不许"按最终尺寸另画一套"）

| 渲染尺寸 | 视觉描边 |
| --- | --- |
| 13px | 1.22 |
| 14px | 1.31 |
| 16px | **1.50** |
| 24px | 2.25（即源画尺寸） |
| 40px | 3.75 |

### 1.4 图标清单

- **五大类**：模型（立方体）/ 材质（材质球）/ HDRI（球+环）/ 其他（文档）
- **功能**：文件夹 / 搜索 / 设置（齿轮）/ 删除 / 网格 / 列表
- **空态（40px）**：收纳（库为空）/ 筛选漏斗（无匹配结果）/ 指针（未选中资产）
- **窗口控制**：最小化 / 最大化 / 还原 / 关闭 —— 全部 SVG，16px 渲染，`currentColor`；关闭钮颜色仍由 `.win-btn-close` 的 danger 决定

### 1.5 左栏图标范围（已拍板）

**只有五个内容大类有图标**；`全部`、`SU 版本`、`风格`、`来源` 保持纯文字，`设置` 有一个齿轮。
理由：筛选入口与内容大类在视觉上要分层，图标全铺满会让左栏变成一排等重的点。

### 1.6 emoji 退役

界面内**不再出现任何 emoji**。原三处（`🧰` 库为空、`📦` 无匹配、`👈` 未选中）全部替换为 1.4 的空态图形。

## 2. 顶栏与导入 CTA（改 v0.2 §3.1）

| 项 | v0.2 原口径 | v0.2.2 新口径 |
| --- | --- | --- |
| 导入压缩包 CTA 位置 | 顶栏，132×32 唯一 CTA | **左栏底部、设置行上方**，`w-full` 撑满侧栏，h32 |
| 顶栏组成 | Logo → 视图切换 → CTA → 搜索 → 窗口控制 | Logo → 弹性空白 → 视图 → 密度 → 搜索 → 窗口控制 |

- 顶栏不再有 CTA，全应用只有左栏底部一个主行动点。
- 搜索框展开逻辑**不变**（右对齐 380px，从弹性空白取宽，不会挤压分段控件）。
- 空库引导页内的「选择压缩包导入」按钮**保留**：它只在库为空时出现，属首次使用引导，不是常驻 chrome。

## 3. 卡片 hover（新增，v0.2 未定义）

| 项 | 值 |
| --- | --- |
| 位移 | `translateY(-2px)` |
| 时长/缓动 | 150ms ease-out |
| 浅色 | 投影 `--shadow-card` → `--shadow-card-hover: 0 12px 28px rgba(100,116,139,.16)` |
| 深色 | **不加投影**（深色 `--shadow-card: none`，加多少都看不见）→ 底色 `--card` 提到 `--bg-elevated`（`#1C1C1E` → `#242428`） |
| 选中态 | **不被 hover 覆盖**（规则用 `:not(.card-selected)` 限定） |

## 4. 卡片密度（新增，三档）

| 档 | 网格下限 | 900px 中栏约列数 |
| --- | --- | --- |
| 大 | `minmax(240px,1fr)` | 3 |
| 中（默认） | `minmax(184px,1fr)` | 4 |
| 小 | `minmax(132px,1fr)` | 6 |

- 控件：顶栏视图切换右侧，同款分段控件（`rounded-seg-group` + `rounded-seg`），三钮文字「大 / 中 / 小」。
- **Ctrl+滚轮**：只在三档之间切换（不做无级缩放），累积 ≥50px 才切一档，到顶/到底不再触发。
- 持久化：`Settings.gridDensity`。
- 实现注意：三个 class 必须是**完整字面量**（`Record<GridDensity, string>`），Tailwind 扫描不到拼接字符串。

## 5. 双击 → 中栏文件夹视图（改 v0.2 §4 交互）

| 项 | 旧 | 新 |
| --- | --- | --- |
| 双击卡片 | 开系统资源管理器并选中主模型文件 | **中栏切换为该资产的文件列表** |

- 中栏头改为：`← 返回` + 资产名（17px semibold）+ 「N 个文件 · 合计大小」；排序胶囊与帮助文本在该视图隐藏。
- 文件行：类型图标（图片 / 模型 / 其他）+ 文件名 + 扩展名徽标 + 大小。
- 排序（**2026-10-22 用户改口径**）：**模型 → 图片 → 其他**；模型组内 **`.skp` 优先**，其余按自然序（`2.jpg` 在 `10.jpg` 前）。
  - 原口径是"图片 → 模型 → 其他"，用户实测后要求改：「模型的界面，就是点进来的这个文件夹，SKP 后缀的这一个文件应该排在第一位，而不是 JPG 这些材质排在第一位」。
  - `.skp` 优先只作用于模型组（一个包里同时有 `.max` / `.obj` 时仍按自然序，**不**擅自给其它扩展名排优先级）。
- 双击文件行 → 系统默认程序打开；打开失败给提示（不静默）。
- 文件行可拖出（`startDrag`）。
- `Esc` 返回；弹窗在场时由弹窗先吃 Esc。
- **「在资源管理器中显示」保留在右键菜单**，作为后门。

## 6. 左栏「材质」合并节点（配合 `docs/14`）

- 大类导航从 5 行变 4 行：模型 / **材质** / HDRI / 其他（`KIND_NAV_ORDER`）。
- 「材质」节点计数 = 贴图 + 材质预设 之和；点击筛选 `kind: 'materialGroup'`。
- 展开后给两个 kind chip（贴图 / 材质预设），点 chip 精确到单一 kind。
- 图标沿用材质球。

## 7. 拖拽归类（新增）

| 手势 | 行为 |
| --- | --- |
| 拖**整张卡片** | **拖出到建模软件**（保留，系统级拖拽，高频核心动作） |
| 拖**卡片左下角抓手**（hover 淡入） | **应用内归类**，拖到左栏分类节点松手即归类 |

- 抓手 14px 六点 SVG，`--text-tertiary`，`group-hover` 淡入、不占位、不吞点击。
- 投放高亮：`bg-accent-tint + text-accent-text`。
- 松手归类后弹 5 秒撤销条（复用删除撤销的同一套 toast）；超时只清状态，不再回滚。
- 已在目标分类 → 不发请求、不弹条。
- 跨大类投放 → 整批取消 + 提示，不产生半成功状态。

> 为什么不能共用同一手势：整卡拖会调 `webContents.startDrag`，一旦触发就交给操作系统，应用内再也收不到 HTML5 `drop`。两个手势必须分开。

## 8. 材质球入口（改）

| 项 | 原 | 新 |
| --- | --- | --- |
| 可渲条件 | `kind === 'material'` 且识别出 PBR 槽位 | **属于材质大类**（贴图 / 材质预设）且**有图片文件** |
| 槽位识别失败 | 不给入口 | 兜底：第一张图当基础色（`albedo`） |
| 网格缩略图 | 走封面 | **不变**（网格用于认出是哪张图，球留给详情面板） |
