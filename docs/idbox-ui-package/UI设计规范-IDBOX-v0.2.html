三、关键组件速查

组件规格要点
搜索框默认收起 32×32 仅图标；点击右对齐展开 380px，右缘与右栏详情面板齐平；失焦收起
导入压缩包 CTA132×32 实心 accent，唯一主 CTA；重新扫描不放顶栏（在设置·导入）
窗口控制（自绘）28×28 方钮 r7；最小化/最大化灰，关闭钮 danger 红；hover 浅色 rgba(0,0,0,.06) / 深色 rgba(255,255,255,.08)
资产卡片所有缩略图统一 1:1（用户拍板四卡等高，模型图裁切居中）；r16；浅色柔影代描边；选中：2px accent 描边 + 右上角 22×22 蓝对勾徽章
多选操作条白/242428 底 r14 投影，相对中栏水平居中悬于网格底部；已选胶囊 → 指派分类（实心蓝）→ 删除（danger-tint）→ 取消
详情文件槽位按 基础色/法线/粗糙度/AO/置换/元数据/预览/其他 分组；每行可单独拖出到 SU/D5
删除撤销确认 + 底部 toast 内 5 秒撤销条（蓝底"撤销 Ns"倒计时）
设置弹窗760×560，左 tab（172px）右内容；导入 tab：处置三档单选+并发 stepper+重新扫描；外观 tab：主题三选卡（未实现项禁用标"v0.2 留位"）；关于 tab：版本号胶囊醒目+检查更新留位
自定义渲染只两个滑块：反光强度、凹凸强度；保存→离屏渲一帧存 JPG，coverSource='manual'
