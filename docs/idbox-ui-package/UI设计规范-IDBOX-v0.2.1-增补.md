# ID BOX · UI 设计规范 v0.2.1 增补（仅记录用户 2026-10-14 16:04 新拍板）

> 本增补不推翻 v0.2 正文，只覆盖以下两处；其余仍以 v0.2 为准。
> 版本号纪律：v0.2 已发布不可改内容，本次以 v0.2.1 记录。

## 增补 1 · 自定义渲染画布改白底（覆盖 §3.7）

- 渲染画布背景由近黑 `#0D0A07` 改为**白底**（浅色主题 `#FFFFFF`；深色主题仍 `#1C1C1E`）。
- 理由：用户原话「渲染完以后希望是白底的，现在是黑底的」。存 JPG 时背景即所见白底。

## 增补 2 · 自定义渲染面板新增第三个滑块：UV 大小

- 滑块顺序：反光强度 → 凹凸强度 → **UV 大小（贴图平铺倍率，默认 1.0，范围建议 0.1–4.0）**。
- 拖动即时重渲，与另两个滑块同口径；保存时三参数一并写入（存 JPG 快照，参数可挂 `renderParams`）。
