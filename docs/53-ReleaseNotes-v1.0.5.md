上一版发布是 **v1.0.4**。这一版是装机反馈后的收口，改动不多但每一条都能摸到。细节与验收证据见仓库里的测试报告。

---

## 提示不再挡在屏幕中间

- 提示气泡从屏幕正中央搬到**屏幕底部居中贴底**，不占视线中心。
- **统一 3 秒自动消失**，不用再手动叉掉。「已还原」「已归类」这类提示自己走；`✕` 保留作兜底，想提前关掉仍然可以。
- 导入队列从底部上移让位，两者不会叠在一起。
- 删除撤销的宽限期仍是设置里那一档（不等待 / 3 秒 / 5 秒），和这个 3 秒是两件事，互不影响。

## D5A 不再是「材质」

- 修了一个判错：`.d5a` 整包入库后卡片显示成材质卡、指派分类弹窗给的是材质词表。根因是封图被算进包内文件里，重算主类型时贴图排在 D5A 前，整包被判成材质。现在按**来源**剔除「是封面」的文件再算主类型，真正「模型包 + 贴图」和 PBR 材质包的语义不动；已经入库的那批不用迁移，点一次刷新即自愈。
- D5A 只是一种格式，和 SU / 3DMAX 同级。卡片现在**同时**有「模型」角标和紫色 `D5A` 格式角标，格式筛选面板里 D5A 那行的文字也改成紫色。小字用的深压紫是实测过对比度的新值，不是凭感觉取的色。

## 「待补分类」只认一级

- 一级已经指派就算已分类，不再因为二级空着就一直挂在「待补」上。
- 该频道没有二级级联词表的资产（比如 HDR）本来就没法填二级，本来就不该计入待补。
- 拿真实库核过账：137 条里按旧口径挂 50 条待补，按新口径 0 条。

## AI 辅助分类整个拿掉

- 设置里那张「AI 辅助分类」卡、背后的调用链、相关开关全部删除。
- 理由：线上 API 全部实测接不通，这条功能从来没有真机验证过。老配置文件里带这个键不会炸：读档不报错，其它字段保住，输出不再含该键。

## 插件（SketchUp）

- **模型卡改成双击**才插入。单击只做「选中 + 提示」，以防点错卡半天；材质双击建材质的口径不变。
- 面板取消深色适配（以前那套深色段实际不生效），几处点了没反应的假控件清掉：「+ 在 ID BOX 里导入」整块删掉，齿轮删掉只留一行纯文字版本号 + 「设置请在 ID BOX 主程序」。
- **左栏三级分类树**：大类 → 一级 → 二级。二级箭头只对**真有过二级值**的一级画，不画空箭头。
- **插件版本与主程序同号**：以前插件自成 1.3.0 序列，面板里看到两个不同的数字容易误解，1.0.5 起两条编号合并成一条。
