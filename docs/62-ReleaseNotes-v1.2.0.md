这一版的重头是「把文件夹用起来」：可以照自己的模板一键生成项目文件夹、把常用文件夹钉到首页快速访问、双击钉选卡直接在软件里翻文件。首页加了一排筛选气泡，文件夹的底纹和切档动画也能自己调。SketchUp 插件的排序补齐到和主程序一致。

---

## 新建项目：照模板一键生成

- **首页就有入口**：文件夹区末尾那张「新建项目」卡片点开就是四步向导 —— 选模板 → 填编号和名称 → 选存放位置 → 确认。编号建议填，但可以跳过；不填就直接用项目名当文件夹名。
- **模板可以自己改**：设置 → 库 里新增「项目文件夹模板」，内置一套 4 个一级、15 个二级的标准结构；可以新建、复制、改名、删除，节点树能编辑到 4 级。模板会跟着「一键打包」一起导出去，换电脑不丢。
- **生成前后都安全**：目标位置已经有同名文件夹时整体拒绝、一个都不建，不会覆盖你已经放进去的东西；建好之后会在资源管理器里定位到新文件夹，并自动钉到首页快速访问。

## 首页快速访问：常用文件夹钉在这

- **钉你自己的文件夹**：首页文件夹区右键「添加快速访问」，或在文件浏览器里右键文件夹选「添加到首页快速访问」，就能把一个磁盘文件夹钉到首页。右键可以左移 / 右移排序，也可以移除 —— 移除只是从首页拿掉，磁盘上的文件夹一个都不动。
- **悬停自动滚**：文件夹排超过一屏时，鼠标移到左右边缘就会自动往那边滚。动效性能调到「流畅」档会自动关掉这个悬停滚动，手动滚动照常。
- **文件夹底纹可以换**：右键任意文件夹「更换底纹」选一张本地图片，图会复制进本机缓存、下次断网也在；右键「恢复默认底纹」随时退回原样。
- **一排气泡切着看**：文件夹下方新增「全部 / 素材板块 / 项目文件夹」三个气泡，点一下只切换首页显示的文件夹，不离开首页。切换是柔和淡入，不闪。「新建项目」卡片只在「项目文件夹」档出现。

## 应用内文件浏览器：双击文件夹直接翻

- **不用跳去资源管理器**：双击钉选卡进入文件夹后，是一套按文件资源管理器习惯做的浏览界面 —— 面包屑逐级回跳、双击子文件夹下钻、双击文件用系统默认程序打开。
- **返回更清楚**：进入深层目录后，返回路径一目了然，不用一路点面包屑回到顶。
- **只读，不动你的文件**：这一版只浏览、不提供在软件里新建 / 改名 / 删除；越界路径、软链接、`..` 跳转全部在主进程挡掉，单次最多列 2000 项。

## SketchUp 插件

- **排序补齐到 8 档**：最近使用 / 最常使用 / 最近导入 / 按名称 / 按体积 / 按 SU 版本 / 按一级分类 / 按文件数，下拉选档 + 独立的升序降序按钮；这一档没有数据的排序项不会出现在列表里。
- **「最常使用」和主程序同口径**：按真实使用次数算，两周前那次大约只算一半，和主程序的衰减公式一致。
- **卡片信息更全**：主程序写给插件的快照补上体积、导入时间、最近使用、使用次数四个字段；缺字段的旧库照常显示，不会报错。

## 修复与改进

- **文件夹退场重做**：双击文件夹进入模型 / 材质页时，卡片有时会卡在屏幕中间只剩半截 —— 这一版按完整叙事重做：文件夹从点击位置移到屏幕中心，到位后才开始高斯模糊，并在模糊后面缩小直至消失，最后切到目标界面。
- **深色的文件夹背板不再透得过头**：默认底纹后面那块板提到 20% 白，卡片和背景拉得开。
- **切档动画从闪烁改成渐入**，并只动透明度，不再掉帧。

## 升级提示

1. 先退出正在运行的 ID BOX，再运行 `IDBOX-Setup-1.2.0.exe` 覆盖安装，库与设置原地保留。
2. 插件与本体必须同号：打开设置 → 同步插件，在 SketchUp 那张卡上点「安装插件」或「更新到 1.2.0」，导出后在 SketchUp 的扩展管理器里覆盖安装，重启 SketchUp。
3. 装了多个 SketchUp 版本的，逐台更新一遍。

**下载说明**：安装包同时提供了 `.zip` 版本，解压后得到的还是同一个 exe。有的浏览器会把没做过代码签名的 exe 标成不安全、直接拦下载，走 zip 通常更顺；Windows 第一次运行时仍可能提示「未知发布者」，这是因为安装包没有代码签名证书，不是文件被改过 —— 想核对的话可以比对页面上的 SHA256。
